# Real Estate Housing Price Prediction

## Project Overview
This project uses Machine Learning regression algorithms to predict median house values using the California Housing dataset.

## Objectives
- Analyze and clean the housing dataset.
- Handle missing numerical values.
- Encode categorical features.
- Train and compare Linear Regression, Ridge Regression, and Lasso Regression.
- Evaluate models using MAE, RMSE, and R² Score.

## Dataset
- Rows: 20,640
- Features: 9 input columns
- Target: `median_house_value`
- Missing values: 207 in `total_bedrooms`

## Machine Learning Models
1. Linear Regression
2. Ridge Regression
3. Lasso Regression

## Evaluation
The models are evaluated using:
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Tools and Libraries
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook.

## How to Run
1. Install the requirements using `pip install -r requirements.txt`.
2. Open `house_price_prediction.ipynb` in VS Code.
3. Select a Python kernel.
4. Run all notebook cells in order.

## Outputs
The `outputs` folder contains model comparison results, predictions, and visualization graphs.
